# Maintainers

The people who review and merge changes, triage issues, cut releases and
answer security reports, as [GOVERNANCE.md](GOVERNANCE.md) describes. The
authors of the code before it was public are credited in
[AUTHORS.md](AUTHORS.md); contributors since are credited by the commit
history.

| GitHub | Areas | Since |
|---|---|---|
| @bhavathi-loop | everything (`.github/CODEOWNERS`) | the public release, 2026-09 |

Emeritus: none yet.

To reach the maintainers about something that is not an issue or a pull
request: `security@loopai.com` for vulnerabilities and conduct
([SECURITY.md](SECURITY.md), [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md));
everything else belongs in an issue ([SUPPORT.md](SUPPORT.md)).
